# starbucks_historical_hiring

Search for accessible **historical** Starbucks frontline job-posting data (the snapshot scrape has no time dimension).

- **Output:** `outputs/historical_hiring_sources.md` (coverage, roles, dates, removal dates, location, access, bias).
- **Method:** vendor documentation and university-library pages via web search (2026-10-01); the Internet Archive was tested in `../starbucks_archive`.
- **Conclusion:** LinkUp or Revelio Job Postings (WRDS) are the strongest candidates. Both record posting and removal
  dates for careers-site requisitions. Access is unconfirmed. Revelio *workforce* (profile) data should not be used for frontline staffing.
- **Limitations:** no data pulled; access depends on institution.
- **Investment suitability:** high if accessible, because it is the only route to a historical trend.
