# starbucks_thesis_tests

Pre-registered tests of the staffing thesis: what would support it, what would contradict it, and what can be done today.

- `outputs/thesis_tests.md`: Tests A–F (dependent / independent variables, data, expected sign, alternative explanations, falsifying result, feasibility today).
- `outputs/national_writeup_template.md`: structure for the national write-up. Conclusions are left blank until the national data exists.
- `outputs/prioritization.md`: ranked table of all workstreams.
- Inputs come from the sibling folders; this folder holds no data.
